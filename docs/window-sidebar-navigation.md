# 窗口侧边栏导航

公共组件：`frontend/src/components/SidebarWindow.tsx`。

## 层级

- 一级：功能分组，例如 Redis、SQLite、Connect。
- 二级：分组下的独立页面，通过导航项 `children` 定义，最多两级。Redis 使用数据浏览、命令工作台、本地服务。
- 操作：新建、刷新、测试连接、保存等仍位于页面内容区。

没有子页的窗口继续使用现有单层配置。父节点和子节点的 ID 必须在窗口内唯一；父节点不再承担独立内容页，默认打开第一个子页。

## 选择和恢复

业务传入当前叶子页面 ID。组件计算所属一级分组，分别显示一级与二级选中状态。一级导航和二级导航使用独立、有名称的 tablist，内容区关联当前页面标签。

同一窗口挂载期间，一级分组恢复最近访问的子页；首次访问打开第一个子页。跨刷新当前页面由业务 Redux 持久化恢复。数据页偏好升级至版本 5，旧 redis 迁移为 redis-browser，旧 sql 继续迁移至 connect，已有连接记录保留。

每层导航各自支持方向键、Home、End，Tab 在两层及内容之间移动。激活后保留焦点。桌面使用侧栏内分区和子页缩进；窄窗口一级在第一行，二级在第二行，允许横向滚动。

Redis 的数据浏览与命令工作台共用同一个浏览器实例，切换二级页面不丢失连接及编辑草稿。本地服务独立渲染，不依赖连接目录请求成功。离开 Redis 时沿用现有临时状态清理规则。
