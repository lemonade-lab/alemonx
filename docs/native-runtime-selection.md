# 本机 Node.js 与 Python 版本选择

环境检查只报告实际可执行文件的状态，不修改工作台进程的 PATH。安装其他工具时仅补充缺失目录，保留已有目录的优先级，避免 Git 等系统工具所在目录覆盖已选择的 Node.js。

在环境页切换 Node.js 或 Python 后，工作台将选择保存到当前服务账户主目录下的 `.alemonx/runtime-selection.json`。服务启动时先恢复 Node.js，再恢复 Python；尚无 Node.js 选择记录时，兼容读取已有 NVM 默认版本。

版本切换影响工作台后续启动的进程。已经运行的机器人和终端需重新启动才能继承新环境。用户终端有自己的环境，终端的 `node --version` 不代表工作台后台服务正在使用的版本。

Python 切换直接使用已安装版本的 `bin` 目录，不执行 `pyenv global`。Node.js 切换也不改写用户的 NVM 默认别名。安装入口和版本列表复用同一 NVM 目录；已有用户 NVM 时继续复用，否则使用工作台内置 NVM。

如果所选解释器无法运行，切换失败并保留原环境；如果保存选择失败，工作台恢复原 PATH 并报告错误。配置随服务账户保存，迁移到另一账户或主机时应重新选择当地已安装的运行时。
