# 数据管理

从工作台左下角「系统 → 数据」打开独立窗口，无需选择机器人。
窗口复用工作台其他窗口的侧边栏组件，固定提供 **Redis、SQLite、Connect** 三个入口，支持方向键、Home / End 切换。
启用登录保护时只有超级管理员可见、可访问；未启用时沿用本地工作台的信任模式。不要将未启用登录保护的工作台暴露到公网。

## 对话框与操作反馈

- 主工作区保留连接/对象导航与数据操作；Connect 的新建和编辑连接使用全局表单对话框，测试失败留在对话框内，成功保存或连接后关闭。
- Redis 连接配置、新建键、重命名键、服务高级配置，以及 SQLite 行编辑复用全局 Modal。Redis 连接配置在点击「完成」后才应用；Esc 或关闭不改变当前连接。
- Redis 数据/服务变更、SQLite 写入和忘记连接统一使用全局确认框，不再使用浏览器原生 confirm。取消不会发送对应写请求。
- 弹窗通过 Portal 挂到页面顶层，不受工作台窗口裁切；支持窄屏、主题色、焦点循环与关闭后焦点恢复。嵌套确认时仅最上层处理 Esc；提交期间表单禁止关闭。

## Redis

- 地址留空连接「数据 → Redis → 本地服务」中的服务，也可输入 `host:port` 和本次连接凭据。支持普通 TCP，暂不支持 TLS 和 Cluster。
- 选择数据库编号，用 SCAN 匹配键名并逐批查看。SCAN 不是快照，数据库变动时可能重复或遗漏键；空批次不代表扫描结束，应以游标 0 为准。
- 查看 string、hash、list、set、zset、stream；字符串保存通过 WATCH / MULTI / EXEC 比较原值并原子提交，保留 TTL。值变化、键被删除或提交期间发生修改时拒绝覆盖，请重新读取。可单独调整 TTL、永久保存或删除键；这些操作及手动命令不提供原值比较。
- 命令编辑器采用 JSON 字符串数组，例如 `["HSET", "user:1", "name", "小明"]`。集合可依据返回的游标继续读取，列表可调整 LRANGE 范围。
- 写操作需确认；禁止 FLUSH、EVAL、CONFIG、SHUTDOWN 等全库或服务级操作。二进制值不能通过文本编辑器读写，大响应会拒绝返回。
- 服务启动、关闭、重启、运行时准备和配置统一迁移到「数据 → Redis → 本地服务」，设置页不再重复提供入口。已有配置和数据不变。连接目录读取失败时仍可进入服务管理；外部服务不提供启停或配置修改。
- Redis 内用「数据浏览 / 本地服务」区分数据操作和服务维护；切换这两个视图保留当前键值草稿，离开 Redis 或关闭窗口仍清除临时内容及凭据。
- 默认收起连接参数和高级命令；可显式「测试连接」。顶部显示目标地址、数据库编号和最近请求状态，这不是持久在线连接的健康监测。
- 键空间使用 SCAN 按模式分批浏览；选择键后按类型进入字符串、Hash、列表、集合或有序集合编辑器。Hash/集合类操作仍按批次读取，不能把当前屏幕当作完整快照。Stream 目前只读预览。
- 可创建字符串、Hash、列表、集合和有序集合键，并对已有键调整 TTL、重命名或删除。每项变更均提示目标地址、数据库和键名；不提供 FLUSH、脚本或服务配置命令。命令 Workbench 是高级入口，保留 JSON 字符串数组格式。

## SQLite（默认数据库）

- SQLite 是固定入口，不属于 Connect 中的某个连接。首次打开时自动准备工作区的 `data/default.sqlite`，后续自动打开，不需要填写路径或安装数据库环境。
- 默认库和系统运维库 `ops.db` 分离；不会迁移或覆盖已有数据库。默认库可建表、查询及确认写入，随工作区持久化，备份时包含工作区 `data` 目录。
- 创建失败或已有文件不是合法 SQLite 时展示错误和重试，不覆盖已有文件。创建过程先完成临时数据库，再以不覆盖的方式发布；需要工作区具有写权限、所在文件系统支持硬链接。

## Connect（数据库客户端）

Connect 是独立的通用 SQL 客户端，已从 `SQLiteBrowser` 分离，支持 MySQL、MariaDB、PostgreSQL 和 SQLite。它不是默认 SQLite 的设置页，也尚未完整对齐 Navicat 的所有基础能力。升级进度见 [Connect 升级计划](connect-upgrade.md)。

- 可选择已有连接路径，系统运维 SQLite 也作为可选连接提供。系统运维库由后端强制只读（通过文件身份识别链接别名），请使用业务功能修改。可输入其他已存在 SQLite 文件的绝对路径。路径属于 **ALemonX 服务所在设备**；Docker 中应使用容器内路径。
- 最多保存 50 个命名连接，保存前需测试或连接成功；可编辑、重新测试、保存及忘记。忘记不会删除数据库，SQLite 拼错路径不会创建空文件。
- 远程连接支持主机、端口、用户名、密码、初始数据库；默认 TLS 验证证书与主机名，也可明确关闭 TLS（仅可信网络）。尚不支持自定义 CA、客户端证书、SSH 隧道。
- 连接后选择数据库及 PostgreSQL Schema，搜索表和视图，查看数据、字段结构与索引。表数据每页 100 行，目前无显式排序，可能重复或遗漏；需要稳定结果时手动写 ORDER BY。
- 最多 8 个临时查询页签，支持执行全文或选中 SQL、取消和写入确认。每请求独立连接，不提供跨请求事务或会话变量；PostgreSQL 查询使用所选 Schema 的 search_path。
- 默认使用只读事务查询远程数据库；写入需明确确认并立即提交。数据库账号仍应遵循最小权限原则，只读事务不是限制服务端函数、资源消耗或外部副作用的安全沙箱。
- 每次仅支持一条 SQL；不支持手动事务、批量脚本及存储过程，当前词法限制拒绝反斜杠、美元引号、块注释和只读 INTO。拒绝时不会尝试执行拆分后的语句。
- 远程查询最多 4 个并发、8 秒超时，返回最多 200 行 / 约 1 MiB 行数据；最多 256 列。大整数、DECIMAL 不转换为不精确 JS 数字；二进制列采用 base64。返回限制不是远程驱动或数据库内存硬隔离。
- 浏览器持久化升级为版本 4，将旧 SQLite 路径与名称迁为 SQLite 连接。只保存连接参数与名称，不保存密码、结果或查询文本。
- 切换连接/数据库/Schema 或断开时，已编辑的查询会先请求确认，确认后清除，避免旧 SQL 误用于新目标。关闭窗口或切换顶层功能仍会清除临时内容。

## 内置 SQLite 管理能力
- 连接后浏览表和视图、完整列结构（包含生成列），每页 100 行。优先按主键及复合主键顺序排序；无主键时按可见列排序，相同值之间不保证物理行顺序。分页不是一致性快照，并发更新可能使记录位置改变。
- SQLite 顶部明确显示实际连接目标及只读/写入状态；对象列表支持搜索表和视图。
- 默认只读；执行写入需要开启写入开关并逐次确认。支持单条 INSERT、UPDATE、DELETE、REPLACE、CREATE、ALTER、DROP 等语句，不支持多语句脚本、ATTACH、PRAGMA 或手动事务控制。
- 声明主键的表提供「编辑行 / 删除行」。编辑表单使用 JSON 值保留类型，只生成实际修改字段，排除主键、隐藏列及生成列；操作生成到 SQL 编辑器，**不会立即修改数据**。自动条件包含原始列值，减少并发覆盖风险；影响 0 行时请刷新检查。含 BLOB 或空主键的行需手动编写 SQL。无主键表、视图只能通过明确条件的 SQL 修改。
- 每个工具连接显式开启外键检查，执行约束及数据库声明的级联规则；不会修改数据库既有 schema 或全局进程设置。
- 最多 4 个工具请求同时执行，超出立即返回繁忙。查询最多返回 200 行 / 约 1 MiB JSON 行数据，超出提示截断；BLOB 以 base64 展示，大整数以字符串返回。请求超时为 8 秒。
- 引擎对字符串 / BLOB / 编码行设置 1 MiB 长度限制，并限制 SQL 长度、列数、表达式深度、字节码等，限制在值读取前生效。超大行可能报错，请选择较少字段。单连接建议缓存 2 MiB、临时存储使用文件；这些机制**不是进程总内存硬隔离**，不能承诺任意查询都只占固定内存，也不影响应用其他 SQLite 连接。
- 取消请求不保证回滚已经提交的写入。写入前自行备份；目前不提供撤销或可视化关系设计。

数据库结果、SQL 内容和密码不写入浏览器持久化或数据接口请求日志。浏览器只保留数据库类型偏好、连接配置（不含密码）及旧 SQLite 路径。
旧版「SQL」页签偏好自动迁移到 Connect，已保存的连接路径保留；默认库自动打开不会写入 Connect 的连接历史。
